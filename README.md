# CashRunway

CashRunway is an offline-first mobile application designed to help individuals and founders track cashflow, estimate financial runway, and manage personal budgets.

## Features

- **Local-First Architecture:** Financial records and settings are stored locally on-device using SQLite (`expo-sqlite`).
- **Google Drive Backup & Sync:** Optional private cloud backup to your personal Google Drive application folder (`drive.appdata`).
- **Runway & Cashflow Analytics:** Visual projections and runway estimations.
- **Privacy Centric:** No third-party ads or trackers.
